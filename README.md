**One Bowl of Fire** — one picture of food, drawn entirely in code: a
steaming bowl of ramen in a deep-red lacquer bowl. Golden broth with
chilli-oil gloss, wavy noodles, seared chashu, a soft egg with a molten
yolk, spring onions, sesame and a sheet of nori — chopsticks lifting a
swirl of noodles through rising steam, lit warm against a dark table.

`main.py` draws the picture with PIL and the standard library only — no
network, no stock photos, no text in the image — and writes
`/output/entry.png` (1024×1024).

## Run it

```sh
python3 main.py   # writes /output/entry.png
```
